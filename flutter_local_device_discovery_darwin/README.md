# flutter_local_device_discovery_darwin

Apple platform (iOS and macOS) implementation of the [`flutter_local_device_discovery`](https://github.com/amirsaleemahmad/flutter_local_device_discovery) plugin.

## Usage

This package is the iOS and macOS implementation of `flutter_local_device_discovery`. It should not be used directly. Instead, use the `flutter_local_device_discovery` package.
